# Why there is no front end

The purchasing decisions live in invoice lines, supplier mappings, category assignments and evidence. Ask an agent to read or change them through the CLI. Read-only HTML gives the team a printable snapshot with an as-of time.

A dedicated screen adds live collaboration, mobile entry, interactive filtering, charts and identity controls. These snapshots provide none of those. There is no live refresh, offline synchronisation, drag-and-drop designer or shared login. An operator can add a new view through /new-view or an extra field through /customise.

The free base runs locally with one trusted operator. Enterprise DNA can build the business's required screens, connections and access controls as part of its own version. Do not expose the local database to the internet.
